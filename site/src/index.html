Learn to code, one line at a time.

Copperkeep is a place for kids to learn Python. Their code runs right in the browser, so the server only keeps their progress, and all of it stays on your own network.

Built for a family, a classroom, or a tutoring room

A small system with few moving parts, designed so a child can use it without a grown-up standing over them.

  • ▶

    Code runs in the browser

    Python runs as WebAssembly on the learner's own device. There's no sandbox server to harden and no per-learner compute cost.

  • ★

    Mastery, not completion

    A skill model decides when a learner moves on. Mastery gates a branch, never a lock, so someone who's stuck always has a door.

  • Aa

    Reading levels

    The same skills and the same tests, in words that fit the reader. Reading level is part of the lesson format, not a separate course.

  • ⌂

    Private by design

    No email, no identity provider, no personal data to collect. Sign-in is a group, a name and four numbers, and your learners' work stays on your server.

  • ▤

    A view for the grown-ups

    Accounts, reports and progress for the adults looking after a group of learners.

  • CC

    Open lessons

    The curriculum is its own repo under CC BY-SA 4.0, released on its own calendar. An optional AI tutor is off by default, and it never writes the lessons.

One origin, a handful of containers

Everything is served from a single address and routed by path. That isn't cosmetic: stopping a running program needs SharedArrayBuffer, which needs the browser to see one origin over TLS.

/            web        the app
/content/    content    lesson JSON
/audio/      audio      narration
/runtimes/   runtimes   Pyodide and wheels
/v1/         api        the only dynamic part (talks to Postgres)

All images are multi-arch (amd64 and arm64), so a Raspberry Pi 5 is a fine home.

Install

Pick one. Both use the same images and the same settings. TLS is required, because the browser features it relies on need a secure context.

Kubernetes (Helm)

helm install copperkeep \
  oci://ghcr.io/chinny-labs/charts/copperkeep \
  --version 0.1.13 \
  --namespace copperkeep --create-namespace \
  --set ingress.host=learn.example.com

Works on k3s, Talos and any cluster. Postgres runs in the chart (or point it at your own).

One box (Docker Compose)

cd deploy/compose
cp .env.example .env   # set the secrets
docker compose pull
docker compose up -d

Set COPPERKEEP_SESSION_SECRET and POSTGRES_PASSWORD first. Back up before you need it: see backup and restore.
